# HelloPlus Account Creation Page

This is a simple web application that allows a user to enter a display name,
username, email address, and password to create a mock account. The program
checks that the password is at least six characters long and displays a
confirmation message when the account is created.

The page uses HTML, JavaScript, and the Bootstrap framework. These technologies
could be used in our group project to build the user interface and account
creation/login portions of the application.

## Running the Program

Download or clone the files and open `index.html` in a web browser.
