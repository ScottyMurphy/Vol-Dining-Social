# HelloPlus

## Description
A small program that uses React to create a simple local host dashboard to display the time and date.

## How to Run
Simly use these two commands in powershell and open the local host
- g++ -std=c++17 main.cpp -lws2_32 -o server.exe
- .\server.exe

## Use in Project
This technology could be used in our project to display dashboards with relevant information to the user. Although this dashboard is very basic, the framework for this technology will be very useful and React can be used in order to accomplish this.
