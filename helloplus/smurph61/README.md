# Vol Dining Social - HelloPlus

This program is a simple C++ sign-up and login system for the Vol Dining Social project. This is a simplified version of what we will use later, but it will be an essential aspect of our project.

Users can create an account using an email address ending in `@vols.utk.edu`. After signing up, they can log in using the same email and password. The program only allows a successful login if the entered credentials match an account created during the current program session.

## How to Run

Compile the program with:

```bash
g++ login.cpp -o login.exe
```
Execute the program with:

```bash
./login.exe
